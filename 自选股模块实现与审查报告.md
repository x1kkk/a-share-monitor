## 1. 核心实现自检说明（逐条回答）

### 1.1 持久化与接口

**watchlist.json 如何读写？**

`main.py:52–66` 在 Monitor 初始化时读取后端根目录的 UTF-8 JSON 数组，检查为字符串列表且每项满足 `(?:00|60)[0-9]{4}`，转为 set 分别赋给 live/mock 引擎。文件不存在时自动创建空列表；格式损坏、错误类型或非主板格式会报错并拒绝覆盖，不能声称会自动修复。只持久化代码，不持久化行情或临时雷达状态。

`main.py:68–95` 使用同目录随机临时文件写入排序后的代码数组，执行 flush、os.fsync，再 os.replace 原子替换。只有替换成功才更新内存、清理移除代码的雷达及判定状态，并通过 WebSocket 广播最新自选看板；失败清理临时文件。API 捕获 OSError 返回 503，保持原文件及原自选集合。该顺序依赖单进程、处理函数持久化区间不 await；生产必须继续 workers=1。文件与 `.watchlist-*.tmp` 已忽略，不随代码提交。

**GET / POST / DELETE 与模糊搜索如何校验？**

| 路由 | 实际行为与校验 |
| --- | --- |
| GET /api/watchlist | 沿用 API_TOKEN 认证及 Origin 校验，返回当前模式引擎全部已保存自选行情。已有代码不会因临时缺报价或日历失败从清单消失；不是每次 GET 都重新拒绝历史自选。 |
| POST /api/watchlist | Pydantic 禁止额外字段，代码须为 6 位 00/60。新代码还必须存在于 `eligible_stocks()` 返回的真实行情缓存中，且通过真实交易日历的上市至少 15 个交易日校验。重复添加幂等，返回当前行；非法、过新、缺少可靠元数据时 422。 |
| DELETE /api/watchlist/code | 同样认证和检查 Origin，以集合差集删除；重复删除幂等。DELETE 路径没有额外的正则检查，传入不在集合中的字符串仅无害地保持原集合。它不进行添加时的存在性/成熟度校验。 |
| GET /api/stocks/search?q=招商 | trim + casefold，匹配代码或名称的子串，最多 30 条；空输入或超过 32 字符返回空数组。搜索范围同样是 eligible_stocks。是中文子串匹配，没有实现拼音、编辑距离或模糊音。 |

`fetcher.py` 的共享 `parse_quote()` 在进入真实行情缓存前已限定 00/60、名称非空且不含 ST。`eligible_stocks()`（main.py:97–100）复用 `eligible()` 和真实日历的成熟度计算，不用模拟种子的虚构上市日期验证新自选。持久化加载仅验证格式，不重新联网校验名称/ST/上市资格；后续缺失行情明确标记。

**盘后添加能否立即回显名称与价格？**

正常已有内存行情时可以。盘后/休市进入 mock 模式；`main.py:308–327` 先完成真实元数据校验，再从当前模式 `engine.rows` 返回该股已有完整行。若引擎还未产生该行，则构造真实缓存行；mock 且 simulator.current 有该股时使用模拟当前值，并标记 simulated=true。后备行标记 quote_missing=true，避免将没有完整实时状态的值伪装成新鲜报价。

本次隔离样例将模式设为 mock、session=closed，三个 POST 均断言名称及价格立即回显，返回实值见第 4 部分。但不能承诺任何冷启动都不空白：真实行情或日历未准备好会拒绝新添加；重启后尚未拿到任何报价的已有代码暂以代码作名称，价格未知。即使回显价格，它也是内存最近报价/明确标记的模拟价，不保证是新收到的实盘价格。客户端依赖即时 WS 广播更新看板；REST 成功而连接中断时需等重连，页面会显示连接告警。

### 1.2 VIP 免排队与双栏状态机

**如何免排队优先入普通异动榜？**

`engine.py:211–225` 对自选单独判定窗口涨速至少 2%、当前主力净流入大于零、未达涨停价；普通股票仍要求窗口主力净流入增量大于零。自选条件的 false→true 通过 watchlist_condition 记录，独立产生 vip_signals，即使已在普通异动榜中也能发雷达事件。窗口涨速沿用 `100*(当前价-窗口最早价)/昨收价`，不足两分钟仍可能触发，window_seconds 返回真实跨度；并非必须积累完整 120 秒才判定。

`engine.py:230–249` 将候选分成 vip 和 ordinary，只有普通部分截取 `max(0, 10-minute_count)`；accepted=vip+normal，再逆序插入 OrderedDict 的头部，使同时触发批次 VIP 优先且分数高者靠前；minute_count 仅累加普通入榜数量。已存在普通榜的同一股票不重复插入、不重置原 420 秒时钟，但独立雷达可以新触发。测试先把普通额度占满，再添加待排队代码为自选，验证仍进入第一位、普通计数保持 10。

**左栏置顶静止、120 秒变灰、420 秒移除是否已经实现？**

置顶静止和 120 秒变灰已实现；**当前自选雷达实际是满 300 秒移除，而不是本次提问中的 420 秒**。`engine.py:97` 是 `age >= 300`，App.vue:237、241 也展示 300 秒和相应倒计时，专项测试验证 age=299.999 保留、age=300 移除。上一轮实现任务要求的是“5分钟消失”，本报告如实审查该版本，不擅自改成 420 秒。普通 anomalies 榜使用 cfg.remove_seconds=420，与自选雷达是两个时钟。如果要把自选也统一为 420，需要同时调整后端比较、前端文案/倒计时和专项边界测试，不能只改报告。

`watchlist_events` 为以代码作键的 OrderedDict，每股保留最近一次急拉/首次封板/炸板类型。新事件记录 Entry 并 move_to_end(last=False)，没有新事件的轮次不重排；再次发生事件会刷新该股雷达入榜时刻并置顶。这是每股最新动态摘要，不是保存所有事件的不可变流水。`watchlist_board()` 返回 entered_at、age_seconds、event_type 及 active/expired；active 为 age<120，expired 为 120≤age<300。删除自选或超时移除，涨停不会从独立雷达立即剔除。

行情暂缺时，engine.py:250–254 保留自选旧行并标记 quote_missing=true；全市场截面排名仍只使用本轮有效 rows。抓取失败时 main.py:202–211 仍调用 watchlist_board 推进雷达 TTL，不制造新的封板/炸板。跨日保留自选集合，重置日内雷达与窗口。

**右栏怎样全量展示与排序？**

`engine.py:106–110` 遍历所有自选集合，从 rows 取完整行情；没有任何缓存的代码用 quote_missing 占位。按 `(not is_limit_up, code)` 排序，已涨停在前，其余按代码稳定排列，不要求发生异动。每次引擎更新都返回 watchlist_leaders，不受普通 leaders 的 150 行上限限制，也不受 10 条入榜限额影响。首次封板、封单金额、连板数和开板次数直接复用现有行情状态机；未知盘口/昨日连板数据仍可为 null，前端显示“—”。

### 1.3 强提醒与防打断设计

**事件中有没有字面名称 watchlist 字段？**

没有。`engine.py:140–144` 的实际字段是 `is_watchlist: true` 和 `priority: "vip"`，Notifier 再添加 UUID 字段 id。实际 WS snapshot 包含 watchlist_anomalies/watchlist_leaders，**不包含名为 watchlist 的顶层代码列表**。engine.watchlist 内部集合和本地 JSON 数组并不等于 WS 字段。第 4 部分提供包含 watchlist 的“联合审查视图”，并单独给出从 ASGI WebSocket 实际接收的帧，明确区分二者，避免伪造接口协议。

**VIP 弹窗、顶部横幅与企业微信怎样处理？**

`Notifier.publish()`（notifier.py:35–46）将自选事件排前，VIP 绕过普通 300 秒冷却，每次真实状态转换获得独立 id；模拟与实盘冷却键隔离。普通通知保持冷却；VIP 也不会重复按每轮维持状态生成新事件。

App.vue 根据 is_watchlist 添加 vip-toast 类与星号，watchlist.css:22–25 定义金边、红色边线和 0.9 秒四轮脉冲。logic.js:42–44 中 VIP 保留 12 秒，普通保留 7 秒，按 VIP 优先排序，通知区最多 6 张，普通事件不会挤掉已存在的 VIP。若 VIP 同时超过 6 条，通知卡片仍有数量上限，不能声称每条都会完整展示；左侧雷达保留各股票最近动态。

App.vue:27 仅在不处于自选页签时选择最高优先级 VIP 展示顶部横幅；样式 fixed、z-index=60，点击切换自选页签，可关闭，随对应 Toast 到期。使用 role=alert / aria-live，无浏览器模态 alert，不抢输入焦点，不自动切换页签。减少动态效果偏好会关闭闪烁。

前端 gate 按事件 id 有界去重（最多 2000 个）；连接及重连初始快照不播放历史告警，服务端初始帧 events=[]。声音必须用户点击启用，测试音后才允许合成；VIP 批次优先进入短队列，爆发期间音效有界排队，**不是保证逐条完整播报**，浏览器挂起音频时也可能无法发声。

企业微信当前字面格式是 `### 【模拟演练 ★自选VIP】实时异动`（实盘时为 `【实盘监控 ★自选VIP】`），**不是独立的 `【★自选股】` 前缀**；见 notifier.py:59–74 及第 4 部分实际 markdown 样例。队列上限 1000，worker 独立于行情轮询，单条后间隔 3.1 秒；队列满会记丢弃计数，VIP 排序只作用于当前批次，不会抢占先前已排入的普通消息。默认不向真实群发送模拟信号，本次没有配置或发送任何外部消息。

```python
"""Pure in-memory state machine. Run `python engine.py` for boundary checks."""
from __future__ import annotations

import math
import time
from collections import OrderedDict, deque
from dataclasses import asdict, dataclass, replace
from datetime import datetime, timedelta
from decimal import Decimal

from config import DEFAULT_WEIGHTS, SHANGHAI, Settings
from fetcher import Book, Quote, demo_seed, limit_price


def percentiles(values: dict[str, float]) -> dict[str, float]:
    """Average ranks for ties. A flat market gets 50, not a spurious 100."""
    ordered = sorted(values, key=values.get)
    result = {}
    start, count = 0, len(ordered)
    while start < count:
        end = start + 1
        while end < count and values[ordered[end]] == values[ordered[start]]:
            end += 1
        score = 50.0 if count == 1 else ((start + end - 1) / 2) / (count - 1) * 100
        for code in ordered[start:end]:
            result[code] = score
        start = end
    return result


@dataclass
class LimitState:
    sealed: bool = False
    first_seal_ts: float | None = None
    break_count: int = 0
    touched: bool = False
    book_broken: bool = False


@dataclass
class Entry:
    entered_clock: float
    entered_at: str


class Engine:
    def __init__(self, cfg: Settings):
        self.cfg = cfg
        self.weights = dict(DEFAULT_WEIGHTS)
        self.histories: dict[str, deque] = {}
        self.limits: dict[str, LimitState] = {}
        self.anomalies: OrderedDict[str, Entry] = OrderedDict()
        self.previous_condition: dict[str, bool] = {}
        self.pending: set[str] = set()
        self.minute: str | None = None
        self.minute_count = 0
        self.day = None
        self.rows: dict[str, dict] = {}
        self.watchlist: set[str] = set()
        self.watchlist_events: OrderedDict[str, Entry] = OrderedDict()
        self.watchlist_kinds: dict[str, str] = {}
        self.watchlist_condition: dict[str, bool] = {}

    def clear_windows(self) -> None:
        self.histories.clear()
        self.previous_condition.clear()
        self.pending.clear()
        self.watchlist_condition.clear()

    def set_weights(self, weights: dict[str, float]) -> None:
        if set(weights) != set(DEFAULT_WEIGHTS):
            raise ValueError("weights must contain exactly: " + ", ".join(DEFAULT_WEIGHTS))
        if any(not math.isfinite(v) or v < 0 or v > 100 for v in weights.values()) or sum(weights.values()) <= 0:
            raise ValueError("each weight must be finite, 0..100; total must be positive")
        total = sum(weights.values())
        self.weights = {key: value * 100 / total for key, value in weights.items()}

    def anomaly_board(self, clock: float | None = None) -> list[dict]:
        """TTL advances even when providers are down; prices and seal state do not."""
        clock = time.monotonic() if clock is None else clock
        board = []
        for code, entry in list(self.anomalies.items()):
            age = max(0, clock - entry.entered_clock)
            if age >= self.cfg.remove_seconds:
                del self.anomalies[code]
            elif code in self.rows:
                board.append({**self.rows[code], "entered_at": entry.entered_at,
                              "age_seconds": round(age, 2),
                              "status": "active" if age < self.cfg.active_seconds else "expired"})
        return board

    def watchlist_board(self, clock: float | None = None) -> list[dict]:
        clock = time.monotonic() if clock is None else clock
        board = []
        for code, entry in list(self.watchlist_events.items()):
            age = max(0, clock - entry.entered_clock)
            if code not in self.watchlist or age >= 300:
                del self.watchlist_events[code]
                self.watchlist_kinds.pop(code, None)
            elif code in self.rows:
                board.append({**self.rows[code], "is_watchlist": True,
                              "event_type": self.watchlist_kinds[code], "entered_at": entry.entered_at,
                              "age_seconds": round(age, 2), "status": "active" if age < 120 else "expired"})
        return board

    def watchlist_rows(self) -> list[dict]:
        rows = [{**self.rows[code], "is_watchlist": True} if code in self.rows else
                {"code": code, "name": code, "quote_missing": True, "is_watchlist": True}
                for code in sorted(self.watchlist)]
        return sorted(rows, key=lambda row: (not row.get("is_limit_up", False), row["code"]))

    @property
    def touched_codes(self) -> set[str]:
        return {code for code, state in self.limits.items() if state.touched}

    def update(self, quotes: list[Quote], books: dict[str, Book], now: datetime,
               *, clock: float | None = None, simulated: bool = False,
               yesterday_streaks: dict[str, int] | None = None) -> dict:
        now = now.astimezone(SHANGHAI)
        clock = time.monotonic() if clock is None else clock
        if self.day != now.date():
            weights = self.weights.copy()
            watchlist = self.watchlist.copy()
            self.__init__(self.cfg)
            self.weights, self.day = weights, now.date()
            self.watchlist = watchlist
        minute = now.strftime("%Y%m%d%H%M")
        if minute != self.minute:
            self.minute, self.minute_count = minute, 0
        events, rows, vip_signals = [], {}, set()
        codes = {q.code for q in quotes}
        for code in list(self.anomalies):
            if clock - self.anomalies[code].entered_clock >= self.cfg.remove_seconds:
                del self.anomalies[code]
        for code in set(self.histories) - codes:
            self.histories.pop(code, None)
            self.previous_condition.pop(code, None)
            self.pending.discard(code)

        def event(kind: str, q: Quote, **extra: object) -> None:
            events.append({"code": q.code, "name": q.name, "event_type": kind,
                           "time": now.isoformat(), "price": q.price, "pct": q.pct,
                           "simulated": simulated, "is_watchlist": q.code in self.watchlist,
                           "priority": "vip" if q.code in self.watchlist else "normal", **extra})

        for q in quotes:
            history = self.histories.setdefault(q.code, deque(maxlen=60))
            # No cross-session, long-gap, ex-rights or cash-counter-reset deltas.
            if history and (clock - history[-1][0] > 10 or q.pre_close != history[-1][3]
                            or q.main_inflow < history[-1][2] - 1e10):
                history.clear()
            while history and clock - history[0][0] > 120:
                history.popleft()
            history.append((clock, q.price, q.main_inflow, q.pre_close))
            old = history[0]
            speed = (q.price - old[1]) / q.pre_close * 100
            inflow = q.main_inflow - old[2]
            ceiling = limit_price(q.pre_close)
            at_limit = Decimal(str(q.price)) >= Decimal(str(ceiling))
            state = self.limits.setdefault(q.code, LimitState())
            state.touched = state.touched or q.high >= ceiling or at_limit
            book = books.get(q.code)
            # Two sources may be milliseconds apart. Only price-matched fresh books are usable.
            if book and (abs(now.timestamp() - book.ts) > 15 or abs(book.price - q.price) > 0.005):
                book = None
            pressure = bool(book and at_limit and book.sell_lots >= self.cfg.break_sell_lots)
            if not at_limit:
                state.book_broken = False
            elif pressure:
                state.book_broken = True
            elif book and book.sell_lots == 0:
                state.book_broken = False
            # Missing books cannot undo a known sell-pressure break. A zero-ask book
            # confirms resealing; price-only equality is enough before any such break.
            sealed = at_limit and not state.book_broken
            if sealed and not state.sealed:
                if state.first_seal_ts is None:
                    state.first_seal_ts = now.timestamp()
                    event("limit_up", q)
            elif state.sealed and not sealed:
                state.break_count += 1
                event("break_open", q, break_count=state.break_count)
            state.sealed = sealed
            if at_limit:
                self.anomalies.pop(q.code, None)
            seal_amount = q.price * book.buy_lots * 100 if sealed and book else (0.0 if not sealed else None)
            row = asdict(q)
            row["listed"] = q.listed.isoformat() if q.listed else None
            row.update({"speed_2m": round(speed, 6), "inflow_2m": inflow,
                        "is_watchlist": q.code in self.watchlist,
                        "window_seconds": round(clock - old[0], 2), "limit_up_price": ceiling,
                        "is_limit_up": sealed, "at_limit_price": at_limit, "ever_limit_up": state.touched,
                        "first_seal_time": datetime.fromtimestamp(state.first_seal_ts, SHANGHAI).isoformat()
                        if state.first_seal_ts is not None else None,
                        "first_seal_ts": state.first_seal_ts, "break_count": state.break_count,
                        "consecutive_days": (yesterday_streaks.get(q.code, 0) + 1)
                        if sealed and yesterday_streaks is not None else None,
                        "seal_amount": seal_amount,
                        "seal_float_pct": seal_amount / q.float_cap * 100
                        if seal_amount is not None and q.float_cap > 0 else None,
                        "buy_one_lots": book.buy_lots if book else None,
                        "sell_one_lots": book.sell_lots if book else None,
                        "sell_pressure": pressure,
                        "concepts": [tag.strip() for tag in q.raw_tags.replace("，", ",").split(",")
                                     if tag.strip() and tag.strip() not in {"-", "None", "nan"}],
                        # Main flow already includes super + large; never count super twice.
                        "total_net_inflow": q.super_inflow + q.large_inflow,
                        "total_net_inflow_scope": "super+large", "quote_missing": False,
                        "simulated": simulated})
            rows[q.code] = row
            qualifies = speed >= 2.0 - 1e-9 and inflow > 0 and not at_limit
            if q.code in self.watchlist:
                # VIP radar is independent of ordinary admission and its 420s clock.
                qualifies = speed >= 2.0 - 1e-9 and q.main_inflow > 0 and not at_limit
                if qualifies and not self.watchlist_condition.get(q.code, False):
                    vip_signals.add(q.code)
                    if q.code not in self.anomalies:
                        self.pending.add(q.code)
                self.watchlist_condition[q.code] = qualifies
            if qualifies and not self.previous_condition.get(q.code, False) and q.code not in self.anomalies:
                self.pending.add(q.code)
            if not qualifies:
                self.pending.discard(q.code)
            self.previous_condition[q.code] = qualifies

        ranks = {metric: percentiles({code: row[metric] for code, row in rows.items()})
                 for metric in self.weights}
        for code, row in rows.items():
            row["score"] = round(sum(ranks[m][code] * w / 100 for m, w in self.weights.items()), 2)
        candidates = sorted((c for c in self.pending if c in rows and c not in self.anomalies),
                            key=lambda c: (-rows[c]["score"], c))
        vip = [c for c in candidates if c in self.watchlist]
        ordinary = [c for c in candidates if c not in self.watchlist]
        normal = ordinary[:max(0, self.cfg.max_new_per_minute - self.minute_count)]
        accepted = vip + normal
        # Reverse insertion keeps the strongest of a simultaneous batch at the top.
        for code in reversed(accepted):
            self.anomalies[code] = Entry(clock, now.isoformat())
            self.anomalies.move_to_end(code, last=False)
            self.pending.discard(code)
        self.minute_count += len(normal)
        by_code = {q.code: q for q in quotes}
        for code in accepted:
            if code not in self.watchlist:
                event("anomaly", by_code[code], score=rows[code]["score"],
                      speed_2m=rows[code]["speed_2m"], inflow_2m=rows[code]["inflow_2m"])
        for code in sorted(vip_signals, key=lambda code: (-rows[code]["score"], code)):
            event("anomaly", by_code[code], score=rows[code]["score"],
                  speed_2m=rows[code]["speed_2m"], inflow_2m=rows[code]["inflow_2m"])
        # Missing a code is not evidence of expiry or a limit-up. Keep its last
        # displayed values without feeding stale rows into fresh-market ranks.
        retained = {code: {**self.rows[code], "quote_missing": True}
                    for code in set(self.anomalies) | self.watchlist if code not in rows and code in self.rows}
        self.rows = {**retained, **rows}
        for item in reversed(events):
            code = item["code"]
            if item["is_watchlist"]:
                self.watchlist_events[code] = Entry(clock, now.isoformat())
                self.watchlist_events.move_to_end(code, last=False)
                self.watchlist_kinds[code] = item["event_type"]
        board = self.anomaly_board(clock)
        sealed = sorted((row for row in rows.values() if row["is_limit_up"]),
                        key=lambda row: (row["first_seal_ts"], row["code"]))
        others = sorted((row for row in rows.values() if not row["is_limit_up"]),
                        key=lambda row: (-row["pct"], row["code"]))
        # If >150 stocks seal, retaining every sealed stock takes precedence over the cap.
        leaders = sealed + others[:max(0, 150 - len(sealed))]
        return {"type": "snapshot", "time": now.isoformat(), "simulated": simulated,
                "stock_count": len(rows), "anomalies": board, "leaders": leaders,
                "watchlist_anomalies": self.watchlist_board(clock),
                "watchlist_leaders": self.watchlist_rows(),
                "weights": self.weights.copy(), "events": events,
                "minute_admitted": self.minute_count, "pending_count": len(self.pending)}
```

```python
    monitor = ws.app.state.monitor
    tasks: list[asyncio.Task] = []
    try:
        await ws.accept()
        if settings.api_token:
            message = await asyncio.wait_for(ws.receive_json(), timeout=5)
            if not isinstance(message, dict):
                raise ValueError("authentication object required")
            authorize("Bearer " + str(message.get("token", "")))
        monitor.clients.add(queue)
        await asyncio.wait_for(ws.send_json({**monitor.snapshot, "events": []}), timeout=3)

        async def send() -> None:
            while True:
                try:
                    payload = await asyncio.wait_for(queue.get(), timeout=15)
                except TimeoutError:
                    payload = {"type": "heartbeat", "time": datetime.now(SHANGHAI).isoformat()}
                if payload is None:
                    await ws.close(code=1013, reason="slow consumer; reconnect for current snapshot")
                    return
                await asyncio.wait_for(ws.send_json(payload), timeout=3)

        async def receive() -> None:
            while True:
                # ASGI receive notices disconnects even while polling is initializing.
                await ws.receive_text()

        tasks = [asyncio.create_task(send()), asyncio.create_task(receive())]
        done, _ = await asyncio.wait(tasks, return_when=asyncio.FIRST_COMPLETED)
        for task in done:
            if not task.cancelled():
                result = task.exception()
                if result and not isinstance(result, (WebSocketDisconnect, TimeoutError)):
                    log.debug("WebSocket closed: %s", type(result).__name__)
    except asyncio.CancelledError:
        # The ASGI server/client may cancel this endpoint on shutdown. The only
        # children belong to this connection and are cancelled/joined below.
        pass
    except (WebSocketDisconnect, TimeoutError, HTTPException, ValueError):
        try:
            await ws.close(code=1008)
        except (RuntimeError, asyncio.CancelledError):
            pass
    finally:
        monitor.clients.discard(queue)
        for task in tasks:
            task.cancel()
        if tasks:
            try:
                await asyncio.gather(*tasks, return_exceptions=True)
            except asyncio.CancelledError:
                # AnyIO can cancel again while a TestClient cancellation scope
                # exits. Children have already received cancellation.
                pass
```

```python
class Notifier:
    def __init__(self, client: httpx.AsyncClient, cfg: Settings):
        self.client, self.cfg = client, cfg
        self.last_notify_time: dict[tuple[str, str], float] = {}
        self.queue: asyncio.Queue[dict] = asyncio.Queue(maxsize=1000)
        self.sent = self.failed = self.suppressed = self.dropped = 0

            url = urlparse(cfg.wechat_webhook_url)
            if url.scheme != "https" or url.hostname != "qyapi.weixin.qq.com" or url.path != "/cgi-bin/webhook/send":
                raise ValueError("WECHAT_WEBHOOK_URL must be an HTTPS WeCom group robot webhook")

    def publish(self, events: list[dict], *, clock: float | None = None) -> list[dict]:
        clock = time.monotonic() if clock is None else clock
        accepted = []
        # Prune old cooldown keys, retaining a bounded daily dictionary.
        self.last_notify_time = {key: ts for key, ts in self.last_notify_time.items()
                                 if clock - ts < self.cfg.notify_cooldown}
        for raw in sorted(events, key=lambda event: not event.get("is_watchlist", False)):
            # Simulation never consumes the live-event cooldown budget.
            code = ("mock:" if raw["simulated"] else "live:") + raw["code"]
            key = (code, raw["event_type"])
            if key in self.last_notify_time and not raw.get("is_watchlist"):
                self.suppressed += 1
                log.info("冷却抑制 %s %s %s", raw["code"], raw["name"], EVENT_NAMES[raw["event_type"]])
                continue

            event = {**raw, "id": uuid.uuid4().hex}
            accepted.append(event)
            log.info("%s[%s] %s %s 价格=%.2f 涨幅=%.2f%% 涨速=%s 分数=%s",
                     "模拟" if raw["simulated"] else "实盘", EVENT_NAMES[raw["event_type"]],
                     raw["code"], raw["name"], raw["price"], raw["pct"],
                     raw.get("speed_2m", "-"), raw.get("score", "-"))
            if self.cfg.wechat_webhook_url and (not raw["simulated"] or self.cfg.mock_wechat):
                try:
                    self.queue.put_nowait(event)
                except asyncio.QueueFull:
                    self.dropped += 1
                    log.error("企业微信队列已满：事件 %s 未投递", event["id"])
        return accepted

        mode = "模拟演练" if event["simulated"] else "实盘监控"

        content = (f"### 【{mode}】{EVENT_NAMES[event['event_type']]}\n"
                   f"**{name} ({event['code']})**\n"
                   f"> 价格：{event['price']:.2f}　涨幅：{event['pct']:.2f}%\n"
                   f"> 时间：{event['time']}\n")
        if "speed_2m" in event:
            content += f"> 两分钟涨速：{event['speed_2m']:.2f}%　强度：{event['score']:.2f}\n"
        if "break_count" in event:
            content += f"> 今日开板次数：{event['break_count']}\n"
        return content + f"\n事件编号：{event['id']}"

    async def worker(self) -> None:
        while True:
            event = await self.queue.get()
            try:
                # This worker is independent of the two-second polling task.
                response = await self.client.post(
                    self.cfg.wechat_webhook_url,
                    json={"msgtype": "markdown", "markdown": {"content": self.markdown(event)}},
                    timeout=5.0,

            except (httpx.HTTPError, ValueError):

                self.failed += 1

            finally:
                self.queue.task_done()
            await asyncio.sleep(3.1)

        return {"configured": bool(self.cfg.wechat_webhook_url), "mock_enabled": self.cfg.mock_wechat,
                "queued": self.queue.qsize(), "sent": self.sent, "failed": self.failed,
                "suppressed": self.suppressed, "dropped": self.dropped}
```

```python
AK_BOOTSTRAP = r'''
import contextlib, datetime, json, sys
with contextlib.redirect_stdout(sys.stderr):

        except Exception:

print(json.dumps({"sessions": dates, "streaks": streaks, "streaks_ready": streaks_ready}))

@dataclass
class MarketCalendar:
    sessions: list[date] = field(default_factory=list)
    yesterday_streaks: dict[str, int] = field(default_factory=dict)
    streaks_ready: bool = False
    loaded_for: date | None = None
    error: str | None = "calendar not initialized"

    async def load(self, cfg: Settings, today: date) -> None:
        process = None
        if self.loaded_for != today:
            self.yesterday_streaks.clear()
            self.streaks_ready = False
        try:
            process_env = {key: value for key, value in os.environ.items()
                           if key.upper() not in {"HTTP_PROXY", "HTTPS_PROXY", "ALL_PROXY", "NO_PROXY"}}
            if cfg.http_proxy:
                process_env.update(HTTP_PROXY=cfg.http_proxy, HTTPS_PROXY=cfg.http_proxy)
            process = await asyncio.create_subprocess_exec(
                sys.executable, "-c", AK_BOOTSTRAP, today.isoformat(),
                stdout=asyncio.subprocess.PIPE, stderr=asyncio.subprocess.DEVNULL,
                env=process_env,
            )
            stdout, _ = await asyncio.wait_for(process.communicate(), cfg.calendar_timeout)
            if process.returncode:
                raise ValueError("AKShare calendar process failed")
            data = json.loads(stdout)
            sessions = sorted({date.fromisoformat(x) for x in data["sessions"]})
            if not sessions or sessions[-1] < today:
                raise ValueError("calendar does not cover today; update AKShare")
            self.sessions = sessions
            self.yesterday_streaks = {k: int(v) for k, v in data["streaks"].items()}
            self.streaks_ready = bool(data["streaks_ready"])
            self.loaded_for, self.error = today, None
            log.info("盘前缓存：交易日=%d 昨日连板记录=%d", len(sessions), len(self.yesterday_streaks))
        except asyncio.CancelledError:
            raise
        except Exception as exc:
            self.loaded_for = today
            self.error = str(exc)
            self.yesterday_streaks.clear()
            self.streaks_ready = False
            log.warning("盘前初始化不可用：%s；实盘严格过滤关闭，模拟模式仍可运行", self.error)
        finally:
            if process is not None and process.returncode is None:
                process.kill()
                await process.wait()

    def covered(self, today: date) -> bool:
        return bool(self.error is None and self.sessions and self.sessions[-1] >= today and self.loaded_for == today)

    def listing_is_mature(self, listed: date | None, today: date, minimum: int = 15) -> bool:
        if listed is None or listed > today or not self.covered(today):
            return False
        # At the 15th session (listing day inclusive) the stock is eligible.
        return bisect.bisect_right(self.sessions, today) - bisect.bisect_left(self.sessions, listed) >= minimum

    def session(self, now: datetime) -> str:
        now = now.astimezone(SHANGHAI)
        if not self.covered(now.date()):
            return "calendar_unavailable"
        if now.date() not in self.sessions:
            return "closed"
        minute = now.hour * 60 + now.minute
        if 555 <= minute < 690:
            return "morning"
        if 780 <= minute < 900:
            return "afternoon"
        return "closed"
```

```python
def parse_quote(row: dict, *, now: datetime | None = None) -> Quote | None:

    # missing flows on a traded quote remain invalid below.

def parse_books(text: str) -> dict[str, Book]:
    result = {}
```

```vue
async function watchRequest(path, options = {}) {
  const controller = new AbortController(), timeout = setTimeout(() => controller.abort(), 10000)
  try {
    const response = await fetch(path, { ...options, signal: options.signal || controller.signal,
      headers: { 'Content-Type': 'application/json', ...(token.value ? { Authorization: `Bearer ${token.value}` } : {}) } })
    const result = await response.json()
    if (!response.ok) throw new Error(response.status === 401 ? '令牌无效，请检查连接设置' : typeof result.detail === 'string' ? result.detail : `操作失败（HTTP ${response.status}）`)
    return result
  } finally { clearTimeout(timeout) }
}
function searchStocks() {
  clearTimeout(searchTimer); searchController?.abort(); searchController = null; searchResults.value = []; watchMessage.value = ''
  const query = searchQuery.value.trim()
  searchBusy.value = Boolean(query)
  if (!query) return
  const controller = new AbortController(); searchController = controller
  searchTimer = setTimeout(async () => {
    const timeout = setTimeout(() => controller.abort(), 10000)
    try {
      const rows = await watchRequest(`/api/stocks/search?q=${encodeURIComponent(query)}`, { signal: controller.signal })
      if (searchController === controller) { searchResults.value = rows; if (!rows.length) watchMessage.value = '未找到成熟主板股票，或真实行情/交易日历尚不可用' }
    } catch (error) { if (searchController === controller) watchMessage.value = error.name === 'AbortError' ? '搜索已超时，请重试' : error.message }
    finally { clearTimeout(timeout); if (searchController === controller) searchBusy.value = false }
  }, 250)
}
async function addStock(code = searchQuery.value.trim()) {
  if (watchBusy.value) return
  if (!/^(00|60)\d{4}$/.test(code)) { watchMessage.value = '请输入 6 位主板代码，或点击下方搜索结果'; return }
  watchBusy.value = true; watchMessage.value = ''
  try {
    await watchRequest('/api/watchlist', { method: 'POST', body: JSON.stringify({ code }) })
    searchController?.abort(); searchController = null; clearTimeout(searchTimer); searchQuery.value = ''; searchResults.value = []; searchBusy.value = false
    watchMessage.value = `${code} 已加入自选，行情通过实时连接同步`
  } catch (error) { watchMessage.value = error.name === 'AbortError' ? '保存超时，请重试（重复添加不会产生副本）' : error.message }
  finally { watchBusy.value = false }
}
async function deleteStock(code) {
  if (watchBusy.value) return
  watchBusy.value = true; watchMessage.value = ''
  try { await watchRequest(`/api/watchlist/${code}`, { method: 'DELETE' }); watchMessage.value = `${code} 已移除` }
  catch (error) { watchMessage.value = error.name === 'AbortError' ? '删除超时，请重试' : error.message }
  finally { watchBusy.value = false }
}

function tone(kind = 'test') {
  if (!audio || audio.state !== 'running') return
  // A burst of market events cannot enqueue minutes of delayed notifications.
  if (kind !== 'test' && nextTone - audio.currentTime > 1.2) return
  const notes = { test: [1047, 1568], anomaly: [784, 1047], limit_up: [1047, 1319, 1568], break_open: [523, 392, 262] }[kind] || [784]
  const start = Math.max(audio.currentTime + 0.015, nextTone)
  notes.forEach((frequency, index) => {
    const oscillator = audio.createOscillator(), gain = audio.createGain(), time = start + index * 0.12
    oscillator.type = 'sine'; oscillator.frequency.value = frequency
    gain.gain.setValueAtTime(0, time); gain.gain.linearRampToValueAtTime(0.12, time + 0.008); gain.gain.exponentialRampToValueAtTime(0.001, time + 0.15)
    oscillator.connect(gain); gain.connect(audio.destination); oscillator.start(time); oscillator.stop(time + 0.16)
    oscillator.onended = () => { oscillator.disconnect(); gain.disconnect() }
  })
  nextTone = start + notes.length * 0.12 + 0.1
}
async function enableSound() {
  if (sound.value) { sound.value = false; return }
  try {
    const Context = window.AudioContext || window.webkitAudioContext
    if (!Context) throw new Error('当前浏览器不支持合成提示音')
    audio ||= new Context(); await audio.resume(); nextTone = 0; tone(); sound.value = true; soundError.value = ''
  } catch (error) { soundError.value = error.message; sound.value = false }
}
function dismissToast(id) { toasts.value = toasts.value.filter(toast => toast.id !== id) }
function showEvents(events) {
  toasts.value = alertQueue(toasts.value, events)
  // Reserve the next short audio burst for VIPs without layering every VIP at once.
  if (audio && events.some(event => event.is_watchlist)) nextTone = audio.currentTime
  for (const event of [...events].sort((a, b) => Number(Boolean(b.is_watchlist)) - Number(Boolean(a.is_watchlist)))) {
    if (sound.value && audio?.state === 'running') tone(event.event_type)
  }
}
const writer = serialLatest(async (weights) => {
  saving.value = true; saveMessage.value = '正在保存权重…'
  const controller = new AbortController(), timeout = setTimeout(() => controller.abort(), 10000)
  try {
    const response = await fetch('/api/weights', { method: 'PUT', headers: { 'Content-Type': 'application/json', ...(token.value ? { Authorization: `Bearer ${token.value}` } : {}) }, body: JSON.stringify(weights), signal: controller.signal })
    if (!response.ok) throw new Error(response.status === 401 ? '令牌无效，请展开连接设置' : `保存失败（HTTP ${response.status}）`)
    const result = await response.json()
    if (Object.keys(weights).every(key => Number(draft[key]) === weights[key])) {
      Object.assign(draft, result.weights); acknowledgedWeights = { weights: result.weights, until: Date.now() + 10000 }; dirty.value = false; saveMessage.value = '已保存 · 下个成功行情周期生效'
    }
  } catch (error) { dirty.value = true; saveMessage.value = error.name === 'AbortError' ? '保存超时，点击重试' : error.message }
  finally { clearTimeout(timeout); saving.value = false }
})
function saveWeights() {
  clearTimeout(debounceTimer)
  if (weightTotal.value <= 0) { saveMessage.value = '至少需要一个大于 0 的权重'; return }
  void writer(Object.fromEntries(Object.entries(draft).map(([key, value]) => [key, Number(value)])))
}
function editWeight() { dirty.value = true; saveMessage.value = '等待保存…'; clearTimeout(debounceTimer); debounceTimer = setTimeout(saveWeights, 300) }
function connect() {
  clearTimeout(reconnectTimer)
  if (stopped) return
  connection.value = 'connecting'; firstSnapshot = true
  const ws = new WebSocket(`${location.protocol === 'https:' ? 'wss:' : 'ws:'}//${location.host}/ws`); socket = ws
  ws.onopen = () => { if (socket !== ws) return; lastMessage = Date.now(); ws.send(JSON.stringify({ token: token.value })) }
  ws.onmessage = ({ data: raw }) => {
    if (socket !== ws) return
    try {
      const snapshot = JSON.parse(raw); lastMessage = Date.now()
      if (snapshot.type === 'heartbeat') return
      if (snapshot.type !== 'snapshot') return
      connection.value = 'connected'; retry = 0
      const events = gate.accept(snapshot.events, firstSnapshot); firstSnapshot = false
      data.value = { ...snapshot, ...snapshotRows(snapshot) }; receivedAt.value = Date.now()
      if (snapshot.weights && !dirty.value && !saving.value) {
        const acknowledged = !acknowledgedWeights || Date.now() > acknowledgedWeights.until || Object.keys(DEFAULT_WEIGHTS).every(key => Math.abs(snapshot.weights[key] - acknowledgedWeights.weights[key]) < 1e-6)
        if (acknowledged) { Object.assign(draft, snapshot.weights); acknowledgedWeights = null }
      }
      showEvents(events)
    } catch { /* Keep the last validated snapshot if a server message is malformed. */ }
  }
  ws.onerror = () => { if (socket === ws) connection.value = 'disconnected' }
  ws.onclose = (event) => {
    if (socket !== ws || stopped) return
    if (event.code === 1008) { connection.value = 'auth'; authOpen.value = true; return }
    connection.value = 'disconnected'
    const delay = Math.min(30000, 1000 * 2 ** Math.min(retry++, 5)) + Math.random() * 400
    reconnectTimer = setTimeout(connect, delay)
  }
}
function reconnect() {
  try { token.value ? sessionStorage.setItem('monitor-token', token.value) : sessionStorage.removeItem('monitor-token') } catch { /* In-memory token still works. */ }
  const previous = socket; socket = null; previous?.close(); retry = 0; connect()
}
onMounted(() => {
  connect()
  clockTimer = setInterval(() => { wallClock.value = Date.now(); toasts.value = toasts.value.filter(toast => toast.expires > wallClock.value) }, 1000)
  watchdogTimer = setInterval(() => { if (socket?.readyState === WebSocket.OPEN && Date.now() - lastMessage > 40000) { connection.value = 'disconnected'; socket.close(4000, 'heartbeat timeout') } }, 5000)
})
onBeforeUnmount(() => {
  clearTimeout(searchTimer); searchController?.abort(); searchController = null
  stopped = true; clearTimeout(reconnectTimer); clearTimeout(debounceTimer); clearInterval(clockTimer); clearInterval(watchdogTimer); socket?.close(); audio?.close()
})
```

```javascript
export function localTime(value, seconds = true) {

export function eventGate(limit = 2000) {
  const seen = new Set()
  return {
    accept(events, replay = false) {
      const accepted = []
      for (const event of events || []) {
        if (!event.id || seen.has(event.id)) continue
        seen.add(event.id)
        if (!replay) accepted.push(event)
      }
      while (seen.size > limit) seen.delete(seen.values().next().value)
      return accepted
    },

  }
}
```

### 4.5 样例生成程序完整代码

此程序是报告构建期间的临时验证脚本，不是新增生产后端模块；默认禁用外部通知，采用临时存储路径。


```python
import ssl, sys
sys.path.insert(0, r'.venv/Lib/site-packages')
import json, tempfile, time
from pathlib import Path
from contextlib import asynccontextmanager
from dataclasses import replace
from datetime import datetime, timedelta
from unittest.mock import patch
from fastapi.testclient import TestClient
import main
from config import Settings, SHANGHAI
from fetcher import demo_seed, limit_price
from pre_market import MarketCalendar

cfg = replace(Settings(), mock_mode=True, api_token='', wechat_webhook_url='', mock_wechat=False)
now = datetime.now(SHANGHAI).replace(hour=21, minute=0, second=0, microsecond=0)
seed = [demo_seed()[1], demo_seed()[8], demo_seed()[2]]
with tempfile.TemporaryDirectory() as directory:
    monitor = main.Monitor(None, cfg, watchlist_path=Path(directory) / 'watchlist.json')
    monitor.calendar = MarketCalendar(sessions=[now.date() - timedelta(days=i) for i in range(40, -1, -1)],
                                     loaded_for=now.date(), error=None)
    monitor.fetcher.last_raw = seed
    monitor.mode, monitor.session = 'mock', 'closed'
    engine = monitor.engines['mock']
    clock = time.monotonic()
    engine.update(seed, {}, now, clock=clock, simulated=True)

    @asynccontextmanager
    async def lifespan(app):
        app.state.monitor = monitor
        yield

    with patch.object(main, 'settings', cfg), patch.object(main.app.router, 'lifespan_context', lifespan):
        with TestClient(main.app) as client:
            responses = []
            search = client.get('/api/stocks/search', params={'q': '招商'})
            for quote in seed:
                response = client.post('/api/watchlist', json={'code': quote.code})
                assert response.status_code == 200
                assert response.json()['name'] == quote.name and response.json()['price'] == quote.price
                responses.append({'method': 'POST', 'path': '/api/watchlist', 'request': {'code': quote.code},
                                  'status_code': response.status_code, 'response': response.json()})
            third = seed[2]
            engine.update([seed[0], seed[1], replace(third, price=limit_price(third.pre_close))], {},
                          now + timedelta(seconds=1), clock=clock + 1, simulated=True)
            current = [replace(seed[0], price=round(seed[0].pre_close * 1.03, 2), pct=3, main_inflow=1e7),
                       replace(seed[1], price=limit_price(seed[1].pre_close), pct=10),
                       replace(third, price=round(third.pre_close * 1.01, 2), pct=1)]
            snapshot = engine.update(current, {}, now + timedelta(seconds=2), clock=clock + 2, simulated=True)
            snapshot['events'] = monitor.notifier.publish(snapshot['events'], clock=clock + 2)
            snapshot.update(status='ok', mode='mock', session='closed', source='synthetic_demo_snapshot')
            monitor.broadcast(snapshot)
            snapshot = monitor.snapshot
            with client.websocket_connect('/ws') as ws:
                initial = ws.receive_json()
                assert initial['events'] == []
                monitor.broadcast(snapshot)
                delivered = ws.receive_json()
                assert {e['event_type'] for e in delivered['events']} == {'anomaly', 'limit_up', 'break_open'}
            get = client.get('/api/watchlist')
            persisted = json.loads(monitor.watchlist_path.read_text())
```
